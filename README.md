# Java Fundamentals Lab

A hands-on learning repository documenting Java programming,
computer science fundamentals, JVM internals, and practical
software development skills.

## Objectives

- Understand how Java source code is compiled and executed.
- Explore Java bytecode and the Java Virtual Machine (JVM).
- Develop programming, debugging, and problem-solving skills.
- Build practical projects and document lessons learned.
- Develop a foundation for software development and cybersecurity.

## Environment

- Java Development Kit (JDK): OpenJDK 21
- Operating environment: Termux on Android
- Compiler: `javac`
- Java launcher: `java`
- Bytecode inspection: `javap`

## Learning Approach

Each lab will contain source code, execution instructions,
observations, explanations, and practical exercises.

This repository is for education and legitimate software development.
